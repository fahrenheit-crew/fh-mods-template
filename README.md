## Template Mod for Fahrenheit

This is a minimal example of a valid [Fahrenheit](https://github.com/fahrenheit-crew/fahrenheit) mod. 
It does nothing by itself, but ensures you are prepared to build mods, and provides a simple build system
that allows easy copying to your installation for testing.

## How to use

Open the [modding quick-start guide](https://github.com/fahrenheit-crew/fahrenheit/wiki/Modding-quick-start-guide) in the Fahrenheit wiki and follow along.
