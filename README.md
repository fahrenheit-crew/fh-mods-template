## Template Mod for Fahrenheit

This is a minimal example of a valid Fahrenheit mod. It does nothing by itself,
but ensures you are prepared to build Fahrenheit mods, and provides a simple
build system that allows easy copying of the finished mod to your Fahrenheit 
installation for testing.

## How to use

Open the [modding quick-start guide](https://github.com/fahrenheit-crew/fahrenheit/wiki/Modding-quick-start-guide) in the Fahrenheit wiki and follow along.
